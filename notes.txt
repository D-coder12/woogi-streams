__dirname: A global Node.js variable holding the absolute 
system path to the folder where server.js resides.

path.join(...): Safely concatenates __dirname with 'users.json'. For instance, on Windows, it resolves to
C:\your-project\users.json, while on Linux, it becomes /var/www/your-project/users.json.

app.use(express.json());
Middleware that parses incoming JSON payloads attached to HTTP request bodies 
(e.g., req.body in POST requests). Without this line, req.body would read as undefined.

app.use(express.static('public'));
Configures Express to automatically serve static files 
(index.html, style.css, app.js) directly from the public folder 
to the browser without requiring manual routes for every file.

const SECRET_KEY = 'super_secret_jwt_key';

Where and how do you get your own key?
This is not an API key you apply for or request from a third party. 
It is a secret password chosen by you (the developer) that jsonwebtoken 
uses to sign and verify tokens so users cannot forge fake logins.

Best Practice: Instead of hardcoding it in source code, generate a random 
string using Node.js's built-in crypto library:

node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
Store this generated string inside an environment variable 
(e.g., inside a .env file accessed via process.env.SECRET_KEY).

run server
node server.js
